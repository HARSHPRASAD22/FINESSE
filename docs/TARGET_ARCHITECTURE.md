# Target architecture

## Frontend

- React 19 and TypeScript.
- Vite SPA.
- Supabase Auth.
- Typed API client.
- Shared workspace and business profile state.

## Backend

- FastAPI modular monolith.
- Supabase JWT verification.
- Supabase PostgreSQL application data.
- Supabase private Storage.
- Gemini provider adapter.
- Official-source capture.
- Central deterministic compliance evaluator.
- Persistent assessment, task, report and Navigator records.

## Trust boundary

The browser is untrusted.

FastAPI must verify authentication and workspace membership.

Supabase RLS must provide a second tenant-isolation layer.

Gemini output is candidate data until schema-validated and user-confirmed.

Only reviewed rule versions can be used for compliance conclusions.
